# DBARc Rider

This folder is set up for a Flutter app named DBARc Rider.

## Install Flutter on Windows

1. Install Git if needed.
2. Download the Flutter SDK from the official stable release.
3. Extract it to a folder such as `C:\src\flutter`.
4. Add `C:\src\flutter\bin` to your PATH.
5. Run:

   flutter doctor
   flutter pub get
   flutter run

## Run this app

From this folder:

```bash
flutter pub get
flutter run
```

## Notes

The Flutter SDK is not currently installed in this environment because the Windows script trust prompt is blocking installation. Once the SDK is available on PATH, the project is ready to run.
